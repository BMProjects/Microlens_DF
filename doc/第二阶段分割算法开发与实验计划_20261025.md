## 摘要

1. **基本逻辑。** 磨损评级要测的是“缺陷个体”（每条划痕、每个斑点、每片碎裂区）的几何与分布，而暗场图像记录的是所有缺陷散射光的叠加。稀疏区里，物理规则就能把个体分开；交叠区里，只看局部亮度无法判断交叉点处是两条划痕还是一条分叉、一团亮区是碎裂还是密集划痕，这一逆问题在局部是不适定的，必须借助从数据中学到的形状先验与上下文。因此，机器学习放在“个体分解与语义判定”这一环，标准化、几何测量、分布统计与光学代理量由确定性算法完成，并以实体级指标证明机器学习优于传统方法。
2. **两个并列目标。** 一是分割识别准确率 ≥ 90%（语义分割通用的像素准确率 PA，即 CNAS 公式 A = Σδᵢ/N 中 i 取像素；同时报告 MPA、mIoU 与分类别 IoU，见 2.4 节；镜片等级一致率为物理延伸功能的报告指标）；二是在同一标准输入、同一评价基准上，系统测试与对比机器学习和传统算法在单条划痕完整性、交叉连续性、密集区斑点检出、碎裂界定、宽度与边缘形态、方向分布和光学代理量上的差异。
3. **系统五部分与第二阶段重点。** 导入图像与综合评定沿用并改进前期系统；预处理已直接修正为标准输入图像；第二阶段的实验与开发集中在智能识别（机器学习分割）与几何/光学分析。
4. **预处理已修正。** 原 7/247 的“合格率”源于质检把缺陷像素算作背景。新流程逐图把背景补偿到 0、把离焦晕斑/宽模糊条纹/雾状底光分离为独立的弥散层、剔除沿边界的宽亮带（如 101l 的镜片边缘亮带），输出 dataset_v3；经核查，101l 的亮带并非配准偏差，配准结果与原流程一致。
5. **评价可信。** 以眼镜为单位划分（247 张来自 124 副眼镜，原划分存在左右片泄漏）；三个独立智能助手盲评分级、用户仲裁；实体级指标依靠合成交叠真值；测试集只用一次。

## 一、背景与必要性

### 1.1 镜片功能依赖微结构的光学完整性

离焦微结构镜片在中周部布置微透镜阵列形成近视离焦信号。DIMS 镜片两年 RCT 中近视进展比单光镜片慢 52%，眼轴增长 0.21 mm 对 0.55 mm [1]；HAL 镜片两年 RCT 中等效球镜进展少 0.80 D、眼轴增长少 0.35 mm，且非球度越高效果越强、佩戴时间越长效果越好 [2]。**推断：** 磨损若改变微透镜区的表面形貌或引入强散射，可能削弱离焦信号。检索未找到定量研究在用镜片磨损对微透镜光学性能影响的公开文献，这是研究空白。

### 1.2 磨损的光学后果

划痕散射光线，在视网膜上形成光幕眩光、降低对比度。航空视觉研究指出眼镜与面罩表面划痕的光幕眩光可能显著影响飞行员视觉 [3]；一项 21 人的小样本研究发现透过划痕镜片的高、低对比度视力均下降 [4]。直接证据有限，本计划不据此设定阈值，而把散射量、位置与面积作为可测物理量。

### 1.3 现有标准不覆盖在用镜片的分区磨损评估

ISO 8980-5 规定了耐磨镜片表面的最低要求 [5]，ISO/TR 21958 综述了各类耐刮擦与耐磨试验方法 [6]；它们评价新镜片膜层的整体耐磨性，不提供在用镜片逐缺陷识别、几何测量与分区分布分析。

### 1.4 必须分析分布

同样长度的划痕在中心区、微结构区、边缘区的光学后果不同。项目实测 50 张 val 镜片的 11 个等级不一致样本中，10 个在 C/D 边界、1 个在 B/C 边界，预测分数均因漏检划痕偏低 1.6–7.4 分。只有把缺陷“在哪里、多长、多宽、怎样聚集”测准，等级才会稳定。

## 二、第二阶段目标与基本逻辑

### 2.1 目标

| 目标 | 内容 | 衡量 |
|---|---|---|
| 识别准确率 | 测试窗口像素准确率 PA ≥ 90% | PA 及按眼镜分组自助法 95% 置信区间；MPA、mIoU、FWIoU、分类别 IoU/Dice 必报（2.4 节） |
| 物理延伸 | 镜片等级、损伤区、分布与光学代理量 | 等级一致率等作为报告指标，不作为 90% 判据 |
| 方法对比 | 在同一标准输入与基准上，系统测试机器学习与传统算法的差异 | 实体级、几何级、光学代理量与镜片级指标（第八章） |
| 系统改进 | 前期系统与第二阶段分割、几何/光学分析对接 | 端到端流程可运行、可追溯（第十一章） |

### 2.2 基本逻辑

1. **测量对象是缺陷个体，图像是散射光的叠加。** 从叠加的亮度恢复个体是逆问题。
2. **稀疏区规则可解，交叠区局部不适定。** 只看局部亮度，无法区分交叉与分叉、碎裂与密集划痕、划痕上的亮点与斑点。
3. **机器学习提供形状先验与上下文。** 它的价值在“个体分解与语义判定”，不在更精细的阈值；因此用实体级指标（单条划痕完整率、交叉连续率、密集区斑点召回、碎裂边界一致性）衡量，而不只看像素 IoU。
4. **传统方法提供物理一致性与可测量性。** 背景补偿、候选证据、几何测量、分布统计与光学代理量由确定性算法完成，可解释、可复现、可溯源。
5. **结论：** 机器学习只放在局部规则不适定的位置，并在同一基准上证明其优于传统方法；在规则已足够的环节保留传统方法。

### 2.3 评价口径

| 层级 | 指标 | 参考来源 |
|---|---|---|
| 像素级（正式，v3.2） | PA（达标判据）、MPA、mIoU、FWIoU、分类别 IoU/Dice | 冻结的人工审核窗口基准（第九章） |
| 镜片级（物理延伸） | 等级一致率与 95% 置信区间 | 评审共识等级（可后置） |
| 实体级 | 单条划痕完整率、交叉连续率、密集区斑点召回、碎裂边界一致性、缺陷单元 F1 | 合成交叠真值（逐条已知）+ 评审锚点单元 |
| 几何级 | 长度、宽度、面积相对误差；方向分布误差；clDice | 合成真值 + 锚点 |
| 光学代理量 | 散射积分、定向眩光指数、碎裂面积占比等的稳定性与等级相关性 | 共识等级（第六章） |

### 2.4 分割识别准确率的定义（v3.2，采用语义分割通用定义）

开发者决定（2026-10-26）：90% 指标采用机器学习论文中语义分割的通用定义，以满足 GB/T 25000.51（ISO/IEC 25051）测试对指标可追溯、无歧义的要求，不自定义区域单元。

**定义（Long, Shelhamer, Darrell, FCN [47]，语义分割评测的标准写法）：** 设 *n*<sub>ij</sub> 为基准类别 *i*、预测为类别 *j* 的像素数，*n*<sub>cl</sub> 为类别数，*t*<sub>i</sub> = Σ<sub>j</sub> *n*<sub>ij</sub> 为类别 *i* 的像素总数，则

| 指标 | 公式 | 在本项目中的角色 |
|---|---|---|
| 像素准确率 PA | Σ<sub>i</sub> *n*<sub>ii</sub> / Σ<sub>i</sub> *t*<sub>i</sub> | **正式指标“分割识别准确率”，阈值 90%** |
| 平均像素准确率 MPA | (1/*n*<sub>cl</sub>) Σ<sub>i</sub> *n*<sub>ii</sub> / *t*<sub>i</sub> | 必报，反映各类召回 |
| 平均交并比 mIoU | (1/*n*<sub>cl</sub>) Σ<sub>i</sub> *n*<sub>ii</sub> / (*t*<sub>i</sub> + Σ<sub>j</sub> *n*<sub>ji</sub> − *n*<sub>ii</sub>) | 必报，选模型的主排序指标 |
| 频率加权交并比 FWIoU | (Σ<sub>k</sub> *t*<sub>k</sub>)<sup>−1</sup> Σ<sub>i</sub> *t*<sub>i</sub> *n*<sub>ii</sub> / (*t*<sub>i</sub> + Σ<sub>j</sub> *n*<sub>ji</sub> − *n*<sub>ii</sub>) | 必报 |
| 分类别 IoU、Dice | 同上，逐类 | 必报（划痕、斑点、碎裂） |

- **类别**：背景、划痕、斑点、碎裂（*n*<sub>cl</sub> = 4）。“不计”像素（标签 255，含有效区外、审核标为不计的区域与“待确认”像素）不参与统计，与 Cityscapes 等基准的 ignore 约定一致 [48]。
- **与 CNAS 公式的对应**：PA 正是大纲 6.3.1 的 A = Σδᵢ/N，其中 i 为测试集中参与统计的像素，δᵢ = 1 当且仅当预测类别等于基准类别，N 为参与统计的像素总数。附录 B.2 写入上表公式即可，无需自定义规则。
- **测试单元**：测试集由冻结的审核窗口（512×512，每片测试镜片 6 个，按中央区/内环/外环分层随机抽取）组成；窗口位置在审核前生成并冻结。
- **必须同时报告其余指标的原因**：暗场图像中背景像素占绝大多数，PA 受类别不平衡影响，全部预测为背景也能得到很高的 PA。图像分析指标共识（Metrics Reloaded [49]、指标陷阱 [50]）明确把“忽视类别不平衡”列为主要陷阱。因此正式报告中 PA 与 MPA、mIoU、FWIoU、分类别 IoU/Dice 并列，并给出“全部预测为背景”时的 PA 作为参照，防止验收时被质疑指标虚高。
- **综合选模规则（开发者决定）**：在调参集上，PA、MPA、mIoU、FWIoU、缺陷类平均 Dice 五项分别排名，取平均名次最优者；平均名次相同时比较 mIoU。另设否决条件：任一缺陷类别（划痕、斑点、碎裂）的 IoU 比当前基线低 2 个百分点以上的方案不入选。名次差异是否显著，用按眼镜分组的配对自助法检验。
- 2.4 节 v3.1 的“区域单元”口径作废。

现有基准的四个缺陷及对策（v3.0 镜片级口径，保留供物理延伸功能使用）：① N = 20 时 18/20 的 95% 区间为 68.3%–98.8%，扩为约 60 张后为 79.5%–96.2%；② 全库无 A 级、B 级仅 12 张，报告如实说明 A 级未验证；③ 原基准由带漏标的框推得，改用独立评审基准；④ 247 张来自 124 副眼镜，原划分把 30 副拆到 train/val 两侧（CNAS 20 张中 13 张的另一片在训练集），改为按眼镜分组划分。

## 四、预处理：标准输入图像（已完成修正）

### 4.1 为什么只做背景补偿，不生成 Z 图

v2.0 计划中的 Z 图（像素值除以本图噪声标准差）是为了让阈值在不同噪声水平的图像间可比，并不是为了兼容 8/12/14 位图像。现有原图为 8 位（BMP 8bpp，3000×4096），前端设备单一，阈值可比的需求可以用“本图噪声标准差作为元数据、阈值写成 k·σ”满足，而不必改变图像本身。因此 v3.0 取消 Z 图：

- 预处理只做背景补偿，背景统一补偿到 0，缺陷像素保持原始计数单位，散射光强信息不被重新标度；
- 每张图的噪声标准差 σ 写入元数据，传统候选层的阈值以 k·σ 表示；
- 机器学习输入用固定的满量程常数缩放（8 位图除以 255），不做逐图归一化；今后接入 12/14 位设备时，按该设备满量程或标定系数换算到统一的物理单位。

### 4.2 修正后的预处理流程

| 步骤 | 做法 | 解决的问题 |
|---|---|---|
| 配准 | 沿用原流程：以高光环为模板的相位相关 + ECC 仿射配准，参数不变 | 经核查原配准有效；101l 的亮带不是配准偏差 |
| 背景补偿 | 减去设备背景模板，再逐图稳健拟合残余偏置（迭代剔除缺陷像素），背景统一为 0；只做加性补偿 | 不同磨损程度导致的曝光与背景亮度差异 |
| 弥散层分离 | 半分辨率形态学开运算提取宽于约 40 像素的低频结构；幅度 ≤ 20 灰度且边缘柔和的部分归入弥散层，亮或边缘锐利的宽结构视为真实缺陷保留 | 离焦晕斑（如 101l、84r 沿圆周排列的晕斑）、宽模糊条纹、雾状底光 |
| 边界宽亮带剔除 | ROI 外缘 200 像素内、宽于 31 像素、与边界接触长度 ≥ 150 像素且 95% 像素距边界 ≤ 120 像素的亮带，从本图有效区域剔除 | 镜片边缘反光、高光环漏光（如 101l） |
| 质检 | 背景统计只在排除缺陷后的像素上计算 | 原判据把缺陷算作背景 |

**输出（`output/dataset_v3/`）：** `images/` 标准输入（背景≈0，原始计数）、`diffuse/` 弥散层（补偿后图像 = 标准输入 + 弥散层，物理光强完整保留）、`valid/` 本图有效区域、`report.json`（配准参数、背景偏置、噪声 σ、弥散层与剔除统计）。实现：`src/darkfield_defects/preprocessing/standardize.py`、`scripts/preprocess_standard.py`。

## 五、智能识别：传统与机器学习的差异与分工

### 5.1 复杂场景下传统方法的结构性劣势（五图试点，项目实测）

| 镜片（由轻到重） | 前景占 ROI | 最大连通域占前景 | 网络状连通域（≥3 分叉点）占前景 | 落入大连通域的点状亮峰 | 碎裂格数（密度阈值 15/25/35%） |
|---|---|---|---|---|---|
| 108l | 0.8% | 4.3% | 53.6% | 12.3% | 0 / 0 / 0 |
| 26l | 5.4% | 44.5% | 91.0% | 68.1% | 53 / 8 / 0 |
| 90r | 14.7% | 81.9% | 95.7% | 84.4% | 292 / 88 / 7 |
| 76r | 22.4% | 95.9% | 98.6% | 97.3% | 464 / 257 / 85 |
| 72l | 21.3% | 81.7% | 96.0% | 82.2% | 400 / 221 / 91 |

注：点状亮峰含划痕上的亮点，对斑点被吞并比例为高估，趋势明确。

1. **交叠完整性。** 中度以上磨损时交叉划痕被连成一张网；二值掩膜中一个像素只能有一个标签，局部夹角规则看不到交叉点两侧的长程走向，密集区每条划痕穿过几十个交叉点，任一点判错都会截断或错接。
2. **斑点突出性。** 密集区 68%–97% 的点状亮峰与划痕连成一体，斑状滤波在交叉点、端点同样响应。
3. **碎裂定义。** 只能用局部前景占比阈值定义，阈值 15%→35% 时 76r 的碎裂面积相差 5.5 倍。
4. **通用局限。** 召回与精度不可兼得，Hessian 类滤波在交叉与分叉处响应弱 [7]，传统方法在复杂纹理、噪声与光照变化下不稳定 [8]，暗场弱划痕与背景在灰度上重叠，单靠阈值无法分离 [9]，裂缝分割研究亦以传统方法难以跨场景泛化为引入深度学习的动机 [12]。

### 5.2 三条识别路线

| 路线 | 组成 | 定位 |
|---|---|---|
| R0 传统 | 以 k·σ 为阈值的迟滞分割、多尺度线状/斑状增强与方向场、形态规则分类、骨架交叉配对 | 完整基线；可解释、无需训练 |
| R1 传统候选 + 机器学习判别 | R0 候选单元 + 多尺度上下文补丁 → 分类器（DINOv2 冻结特征 [20] + 轻量分类头）判定“拒绝/划痕/斑点/碎裂” | 度量机器学习在语义判别（剔除背景结构与误检、定类）上的贡献 |
| R2 物理先验分割 | 输入 [标准图, 线状响应, cos2θ, sin2θ, 斑状响应, r/R]；三个输出头：多标签语义、K 方向中心线（K = 12）、碎裂区域概率 | 度量机器学习在个体分解（穿越交叉、密集区斑点、碎裂界定、弱段连续）上的贡献 |
| U 无监督机器学习（v3.1 升为主线之一） | 训练不使用任何人工标签：物理合成监督 + 真实图像自训练 + 免训练异常热图（5.4 节） | 度量“不付人工标注成本”时机器学习能达到的识别准确率；与 R0、R2 同基准对比 |

R2 的关键设计是**多方向分解**：交叉点处两个方向通道同时为高，后处理在各方向通道内分别追踪，划痕可连续穿过交叉点；多标签语义允许同一位置既是划痕又是斑点；碎裂作为区域级类别，由评审共识标定，并给出局部方向熵、碎片长度分布、填充率等可解释描述子。网络族选 U-Net/FPN 与 HRNet 类结构，对照 SegFormer；中心线头加入 clDice [13]。暗场光学元件缺陷研究普遍采用 U-Net、注意力融合网络与改进检测网络处理弱划痕 [9][10][11]。

### 5.4 无监督机器学习路线 U（v3.1）

**定义。** 路线 U 的模型训练不使用任何人工标签；监督信号只来自三处：图像自身（自监督特征、样本间互评）、物理合成（已知真值的合成缺陷）、传统算法输出（作为含噪伪标签）。人工审核基准只用于评价与模型选择（锚点/调参集），测试集只用一次。

**从前期实验得到的约束（项目实测）：**

| 前期结果 | 对路线 U 的含义 |
|---|---|
| 第一阶段分割（FPN/HRNet-OCR/SegFormer，以 YOLO 框内弱掩膜训练）只能给出损失值，无可信评价；框内弱标签漏标严重 | 伪标签来源的质量决定上限；不使用检测框派生标签 |
| Phase 3B 漏检分析：漏检集中在低对比图像（像素标准差 2.4 对正常 8.9），属域偏移，改检测头无效 | 合成数据须覆盖低对比、低信噪比范围；网络输入保留原始计数（÷255），另以 k·σ 归一化通道作消融 |
| trad_v2 消融：最大收益来自去误检（斑点各向同性、两半线检测）与长尺度弱划痕层；剩余问题是交叉处错拆（目视约 8/12）、待确认碎片 4%–8%、碎裂定义对阈值敏感 | 机器学习的预期收益正好在这三处：交叉连续性、弱线连续性、斑点/亮交叉点/碎裂的语义判别 |
| 三助手试点：划痕网格一致性高（Jaccard 0.97），斑点、碎裂两两 Jaccard 仅 0.36、0.12 | 斑点、碎裂的语义本身定义不稳，须给出像素级可操作定义；无监督语义发现（U4）可辅助定义 |
| dataset_v3：背景 ≈ 0、原始计数、σ 中位 0.91；前景占 ROI 0.8%–22% | 在“图块”层面背景始终占多数，样本间互评、记忆库类方法的前提成立；但单张镜片并不存在“无缺陷正常样本” |

**数据特点带来的关键条件 [推断，U2 第一步验证]：** 暗场成像只收集散射光，宽带照明下不同缺陷的散射近似非相干叠加，相机在饱和以下近似线性，因此交叠处的像素值 ≈ 各缺陷单独成像值之和 + 噪声。若成立，把真实孤立划痕的像素“加”到真实无缺陷背景上，得到的交叉、密集场景在物理上是逼真的，并且逐条真值已知。验证方法：在孤立交叉处比较交叉点亮度与两条线剖面之和，统计饱和像素占比。

**四个组成部分：**

| 编号 | 方法 | 输入/监督 | 产出与用途 | 文献依据 |
|---|---|---|---|---|
| U1 免训练异常热图 | 记忆库/样本互评：训练集全部图块构建记忆库，按 FUN-AD/SoftPatch 思路剔除受污染图块；DINOv3 或宽残差网络浅层特征，图块 2–4 倍上采样以适应 2–5 像素宽的划痕 | 无标签 | 与 trad_v2 **独立**的候选证据；用于基准候选并集（第九章）、发现离焦残余/边缘结构等干扰 | MuSc [33]、MuSc-V2 [34]、FUN-AD [35]、SuperADD [36]、DINOv3 [37]、PatchCore [21] |
| U2 物理合成监督 | ① 从 trad_v2 高置信孤立实例中“剪”下真实划痕/斑点（保留原始剖面），按非相干叠加贴到真实背景区；② 程序化生成（长度、宽度、曲率、走向、亮度、模糊的分布取自 trad_v2 训练集统计，含低对比段）；③ 场景：长划痕多重交叉、平行密集族、碎裂区 + 斑点、划痕上的亮点；④ 干扰负样本：弥散层残余、边缘亮带 | 合成真值（逐条、逐个已知） | 训练 R2 结构网络（多标签语义 + K 方向中心线 + 碎裂），并作为实体级评价（单条完整率、交叉连续率）的真值 | DRAEM [38]、异常合成综述 [39]、合成裂缝训练 [41][42]、程序化划痕合成 [44] |
| U3 真实图像自训练 | 以 U2 模型为教师，在训练集真实图像上生成伪标签；与 trad_v2 一致的像素作为确信标签，不一致像素忽略；学生加强增广（弱-强一致性、Noisy Student），中心线头用 clDice/骨架召回损失；迭代 2–3 轮，每轮用锚点集把关 | 无人工标签 | 消除合成-真实域差；路线 U 的最终模型 | Mean Teacher [28]、UniMatch [29]、Noisy Student [43]、clDice [13]、Skeleton Recall [40] |
| U4 无监督语义发现（可选） | 对候选单元（trad_v2 实例、U1 高分区）提取 DINOv3 多尺度特征，层次聚类 | 无标签 | 发现斑点/亮交叉点/碎片/干扰等自然类别；人工只需给聚类命名，用于完善类别定义与审核分组 | INSID3（DINOv3 聚类）[45] |

**评价与对比。** U1、U3 与 R0（trad_v2）、R2（人工修正标签参与训练的版本）在同一基准上报告 A、P、分类别 A 与实体级指标。若路线 U 达到 R2 的水平，说明人工标注主要用于评价而非训练；若差距明显，差距即为人工标注的价值，如实报告。文献 [46] 采用加权多尺度线检测加断裂重连处理暗场弱划痕，与 trad_v2 思路相近，可作为 R0 的外部参照。


### 5.5 分割模型选型与改进路线（v3.3）

**出发点（开发者决定）：** 数据量小（247 片 / 124 副眼镜）、多样性有限、逐像素标注繁杂，目标是在方便的人工审核下把分割识别准确率做到最高。选型原则：① 同时纳入若干当前 SOTA 方法作为候选，在**同一划分、同一训练预算、同一指标**下复现；② 候选覆盖不同的设计假设，使结果可以相互印证；③ 从有效的环节中组合出改进方法，要求它在本项目数据和公开玻璃划痕数据（MSD）上都达到或超过复现的最强基线。

#### 5.5.1 本数据对模型的要求

| 数据特点 | 对模型的要求 |
|---|---|
| 划痕宽 2–5 像素、弱段接近噪声，交叉密集 | 全分辨率输入，解码器保留 1/1–1/2 尺度；对细长、弯曲结构有利的感受野；连通性损失 |
| 单张 3000×4096，镜片数少但像素多 | 图块训练、强几何增广；按眼镜分组交叉验证 |
| 人工标签只覆盖审核窗口，其余为含噪伪标签 | 支持“不计”标签的部分损失 |
| 输入保留原始计数（背景 ≈ 0，÷255 固定缩放） | 归一化方式可设为固定缩放 |
| 斑点/碎裂/干扰的语义区分依赖上下文，样本少 | 大规模预训练特征有潜在收益 |
| 结果须送第三方测试 | 开源、可复现、推理确定 |

| F 前期方法 | FPN-R34、HRNet-OCR-W18 | — | 前期源域 MSD：0.879、0.866（自定划分与类别合并，不可与论文直接比较） | 对照 |
| — | SegFormer-B2、SAM 交互式分割、无监督异常分割 | — | 前期 0.731；细线偏移；MVTec AD 2 分割 F1 约 0.55–0.63 | 不作候选 |

各组相互印证的方式：若 B、C 组在划痕 IoU 和连通性上稳定优于 A，说明“细长感受野”是有效环节；若 D 组在斑点/碎裂 IoU 上占优，说明“预训练语义”有效；若 A 加骨架召回损失就追平 B、C，说明收益主要来自损失而非结构。每个结论都在本项目数据与 MSD 上分别检验，两处一致才采纳。

#### 5.5.3 改进方法（暂名 DF-Seg）：在 A 骨架上逐项叠加经验证有效的环节

| 编号 | 环节 | 来源 | 是否依赖暗场物理 |
|---|---|---|---|
| M0 | nnU-Net ResEnc-L 骨架与训练配方，ignore 标签，5 折集成 | [51][52] | 否 |
| M1 | 骨架召回损失（划痕类） | [40][54] | 否 |
| M2 | 高分辨率解码段换为蛇形/条带卷积块 | [56][57]，SCSegamba 扫描思想 [53] | 否 |
| M3 | 低分辨率段融合冻结的 DINOv3 或 SAM2 Hiera 特征 | [37][58][59] | 否 |
| M4 | 物理先验输入通道：多方向线响应、走向场 cos2θ/sin2θ、k·σ 归一化强度（来自 trad_v2 前端） | 本项目 R2 设计 | 部分（线响应、走向场通用；σ 归一化依赖背景 ≈ 0） |
| M5 | 训练数据：审核窗口标签 + trad_v2 伪标签（待确认为 ignore）+ 非相干叠加合成交叉（U2） | 本项目 | 是 |

逐项消融：每加一项，在调参集与 MSD 验证集上按 2.4 节综合规则比较，显著才保留。最终方法在两个数据集的测试集上各评估一次。

## 六、几何/光学分析

### 6.1 单条缺陷几何

| 指标 | 方法 | 传统与机器学习的分工（工作假设） |
|---|---|---|
| 长度、条数、交叉关系 | 骨架图；R2 下按方向通道追踪单条划痕 | 机器学习明显更好，是主要收益来源 |
| 宽度与边缘形态 | 孤立段沿法向拟合亮度剖面（宽度、边缘梯度）；交叠段先分离再测 | 孤立缺陷传统剖面拟合更精确、可解释；交叠区需机器学习先分离 |
| 局部亮度变化 | 沿骨架的亮度剖面与积分（原始计数） | 机器学习改善弱段连续性；亮度本身确定性计算 |
| 面积、细长比、圆度 | 实例掩膜 | 由识别质量决定 |

### 6.2 整体分布

| 分布量 | 定义 |
|---|---|
| 分区密度 | 中心区、微结构区、边缘区的长度密度（mm/mm²）、数量密度、面积占比 |
| 径向剖面 | 以 0.05 R 为步长的长度/面积密度随半径变化 |
| 方向分布 | 单条划痕方向直方图、平均合成向量长度（各向异性） |
| 空间聚集 | 最近邻距离指数、Ripley K/L 函数 [31]、热点核密度图 |

整体方向在交叉密集区若用结构张量计算，会把多个方向平均成无意义的均值；按条统计的方向分布依赖 R2 的个体分解。

### 6.3 光学代理量（物理推断，待标定）

| 特征 | 光学后果 | 代理量 |
|---|---|---|
| 散射总量 | 雾度按透射光中偏离入射方向超过 2.5° 的比例定义 [32]；散射越多对比度越低 | 分区散射积分（标准输入 + 弥散层的原始计数之和） |
| 碎裂区 | 向各方向漫散射，单位面积对雾度贡献最大 | 分区碎裂面积占比 |
| 长直划痕及方向 | 细长散射体主要把光散射到与其走向垂直的平面，方向一致时形成定向光条眩光 | 各向异性指数、按方向加权的划痕长度 |
| 斑点 | 小角度前向散射光晕 | 斑点数密度与等效直径分布 |
| 宽度与边缘锐利度 | 边缘越锐利、截面越深，散射角越大（推断） | 剖面宽度、边缘梯度 |
| 功能区 | 中心区影响中央视力与眩光；微结构区散射可能削弱离焦像对比度（推断） | 分区加权 |

本项目没有光学实测数据，这些代理量不直接写成评分公式，而作为第⑤部分的候选输入，由共识等级标定权重；弥散层的保留使散射总量可以完整计算。

## 九、数据、标注与评审分工

### 9.0 工作逻辑（v3.1）：一次审核，三份产出

原始数据没有标注，逐像素人工标注不可行。第二阶段采用“传统算法给出完整初稿，人只做判断题”的方式，一轮审核同时产出三样东西：

```text
            ┌─ trad_v2（R0）初稿 ─┐
247 张标准输入 ─┼─ 高召回分割 hr_segment ─┼─→ 候选并集 ─→ 人工审核（判断题）─┬→ ① 冻结基准（测试区 + 锚点区，仅评价）
            └─ U1 异常热图 ───────┘                    ├→ ② 修正标签（训练集，供 R2/半监督）
                                                        └→ ③ 审核统计：各来源的误检/漏检率 → 改进 R0、U
路线 U（U2 合成 → U3 自训练）只读训练集图像与 trad_v2 输出，不读 ①②；①只用于评价与选模。
```

原则：

1. **先划分，后审核。** 按眼镜分组冻结 训练/调参/测试 后才开始审核与训练；之后一切选择只看训练/调参数据。
2. **测试基准不能只来自 trad_v2。** 测试区的候选取 trad_v2、hr_segment、U1 三个来源的并集，审核员还可以补画漏检；每个基准单元记录来源。否则基准会偏向 trad_v2，机器学习路线的优势无法被测到（循环论证）。
3. **人只做判断题。** 每个操作是“接受/拒绝”“改类别”“两段是不是同一条”“看不清（不计）”，只有漏检才需要画线；按复核队列优先级审核，高置信项抽检 ≥ 10% 估计其错误率。
4. **审核范围按用途分级。** 测试集：分层抽取的窗口内全部单元审核（完整）；调参集：锚点窗口完整审核；训练集：只审核复核队列与模型分歧区（主动学习），其余用 trad_v2 原值并记录“未审核”。
5. **标签带来源与可信度。** 每个单元记录 `source / confidence / reviewed / used_for_training`（沿用 `research_loops/segmentation_program.md` 的弱标签元数据）。

### 9.1 现有数据利用

不新增图像，基于 247 张标准输入图像（124 副眼镜）：按眼镜分层划分测试约 30 副、调参约 8 副、训练约 86 副，异型样本只进训练集；训练集内按眼镜分组 5 折交叉验证；路线 U 的自监督、自训练与合成背景只用训练集（必要时含调参集图像，但不读其标注）；合成真值在无缺陷背景区渲染。第二批数据 ScrachDF_20260318（300 张，无眼镜配对信息）可作为路线 U 的额外无标签训练数据，不进入基准。三助手镜片分级（原 T1）降为物理延伸功能的标定数据，可后置。

### 9.3 五图试点结论与协作优化

试点（108l、26l、90r、76r、72l；详见 `output/review/pilot5/pilot_report.html`）：分级 3/5 三人一致、5/5 有多数；划痕网格 R1–R3 在密集镜片上 Jaccard 0.97，传统划痕结果对多数意见精度 0.86、召回 0.72；斑点、碎裂两两 Jaccard 仅 0.36、0.12；传统斑点格仅 27%、碎裂格仅 12% 被多数认可；R2 存在列举遗漏，长划痕被象限切断。

**审核类别判定规则（v3.2，像素级）：**

| 类别 | 判定 | 说明 |
|---|---|---|
| 划痕（1） | 细长亮线：可沿走向追踪，长宽比 ≥ 5 或长度 ≥ 0.1 mm（15 像素），含浅淡段 | 交叉处两条线的像素都算划痕；划痕上的亮节点若没有独立的圆形光晕，仍算划痕 |
| 斑点（2） | 近似各向同性的亮点或亮斑（长宽比 < 3） | 只标亮核及紧邻的可见光晕，不含远处的弥散光 |
| 碎裂（3） | 亮而无法逐条追踪的碎短线、片状亮区：片段大多短于 0.1 mm、走向杂乱 | 能逐条看清的密集划痕仍标划痕 |
| 背景（误检） | 噪声、预处理残留（弥散光晕、边缘亮带）、算法臆造的线 | 在候选上按 X 或单击拒绝 |
| 不计（255） | 确实看不清是否为缺陷、或类别无法判断的区域 | 尽量少用；“待确认”候选默认不计，能判断的应改为具体类别 |

边界不逐像素修改：接受算法给出的线宽（半高宽掩膜）；只有明显过宽或错位时拒绝该候选，再用画线工具补画。审核服务记录每窗用时，用于估算全量审核成本。

助手预筛：三助手对同一单元独立判定，三人一致的单元按开发者 ≥ 10% 抽检的结果决定是否直接采用，其余进入开发者审核。助手判定不作为最终真值，最终以开发者审核结果冻结基准。审核工具：判断题部分沿用 `review_links.py` 的静态网页形式（键盘作答、本地保存、导出 JSON），漏检补画用 LabelMe（trad_v2 已导出 LabelMe 格式）。

## 十二、风险与对策

| 风险 | 对策 |
|---|---|
| 评价循环论证 | 测试参考与锚点独立构建并冻结，测试集只用一次 |
| 左右片泄漏 | 一切划分以眼镜为单位，B 账号核查 |
| 测试样本量小、A/B 级少 | 测试集约 60 张并报告置信区间；如实说明 A 级未验证 |
| 弥散层分离误删真实宽缺陷 | 幅度与边缘锐利度双判据；弥散层单独保存可回加；重点样本目视复核 |
| 合成真值与真实分布差异 | 合成参数取自真实缺陷统计；实体级结论同时报告锚点单元结果 |
| AI 评审同源偏差 | 三种不同模型、盲评、用户仲裁与抽检 |
| 机器学习不优于传统 | 如实报告，该环节保留传统方法 |
| 232 未合入工作 | 背景锚定迟滞阈值先在 232 提交推送，纳入 R0 |
| 基准偏向 trad_v2（v3.1） | 测试区候选取 trad_v2、hr_segment、U1 并集并允许补画漏检；单元记录来源，分来源报告召回 |
| 只按召回计分被“多报”操纵（v3.1） | 区域精确率 P 同时达标；“不计”区域单独统计 |
| 合成-真实域差（v3.1） | 非相干叠加先验证；合成参数取自真实统计；U3 自训练在真实图像上校正；结论以真实锚点为准 |
| 损伤区阈值缺乏物理标定（v3.1） | 不进入识别指标；按损伤区文档第 7 节完成敏感性与替代论证 |
