研究问题说明_20260404_暗场缺陷分割后结构解析与重叠缺陷识别

一、写作目的

本文档用于对当前暗场镜片缺陷研究中的核心问题进行重新定义与系统化阐述。它不是一份新的实验报告，而是基于现有实验结果、数据现象和工程经验，对“问题本质到底是什么”进行一次理论层面的收束。本文档的目标有三点。第一，明确当前任务与一般语义分割任务的本质差异。第二，把前期实验已经说明的问题提炼成可以被文献研究、工程比较和后续模型设计直接使用的问题框架。第三，为后续调用 GPT 深度研究模式提供一份足够清晰、可扩展、可检索的研究问题底稿。

二、问题重定义：当前任务并不等同于一般语义分割

从实际暗场镜片图像的成像特征看，缺陷通常表现为黑色背景上的高灰度区域。就“缺陷区域是否存在”这一层而言，问题并不属于最困难的分割范式。现有经验已经表明，自适应阈值、简单阈值、传统形态学增强，甚至不依赖深度学习的弱标签生成流程，往往都能较稳定地把大部分缺陷区域从背景中分离出来。换言之，当前任务的第一层困难并不是“每个像素是否属于目标或背景”的二元判别本身。

真正困难的部分出现在分割之后。一个被分割出来的高亮异形区域，未必对应一个单一物理缺陷，也未必天然对应一个明确类别。它可能是一条细长划痕，也可能是多条划痕的交叉网络，也可能是密集划痕堆叠形成的 critical/crash 区域，还可能是片状损伤与线状划痕在空间上局部叠加的复合结构。也就是说，当前问题的核心并不是单纯的像素级前景提取，而是对前景区域进行结构解析、实例拆解、类别解释与区域级风险判断。

如果用更准确的形式描述，当前任务应被写成如下四层问题：

  1. 缺陷区域提取：从暗场图像中稳定得到“哪里有异常高灰度结构”；
  2. 结构单元解析：将已经分出来的复杂区域解析为更有物理意义的形态单元；
  3. 重叠与交叉拆解：在多缺陷相互叠加时，尽可能恢复多个潜在缺陷的关系与边界；
  4. 区域级类别与风险判断：把基础结构、聚集程度、位置与物理量综合成 spot / scratch / damage / critical-crash 等类别与等级解释。

因此，本项目后续真正要解决的，不应被简单表述为“提升语义分割精度”，而应更精确地表述为：在暗场镜片图像中，完成从缺陷区域提取到复杂结构解析、重叠缺陷拆解和区域级缺陷判定的连续推理问题。

三、前期实验对上述判断的支持

现有实验结果已经从多个侧面支持了这一问题重定义。

第一批分割实验显示，深度分割模型在“分出缺陷区域”这件事上已经不是完全无能。源域 MSD 结构对照中，FPN 的 best_val_miou=0.8787，DeepLabV3+ 的 best_val_miou=0.8669，说明在较干净的标签条件下，多尺度分割网络已经能够较好学习缺陷区域分布。私有弱标签微调里，Unet++ 的 best_loss=0.2756，FPN 的 best_loss=0.2813，DeepLabV3+ 的 best_loss=0.2783，说明模型对目标域灰度缺陷区域同样具有可学习性。

但这些实验也说明，真正决定工程可用性的，并不是简单的损失值或者二元区域拟合能力。对历史人工核查样本的物理量分析中，FPN 的 scratch_length_error_mean=0.2266、scratch_area_error_mean=0.5529，明显优于 Unet++ 的 0.8313 / 1.0920 和 DeepLabV3+ 的 0.7001 / 1.4238。这说明不同模型虽然都能输出“某种缺陷区域”，但它们对几何结构、连通性和物理量的表达差异很大。换句话说，问题的关键已经从“能不能切出来”转向“切出来的结构是否具有真实可解释性”。

第二批分割实验进一步支持了这种判断。当前 batch2 结果中，FPN 的源域 best_val_miou=0.8752、私有微调 best_loss=0.2904，仍然是整体最稳的主线；SegFormer-B2 已经跑通，但当前仅达到源域 best_val_miou=0.7313、私有 best_loss=0.3258；HRNet-OCR-W18 的源域 best_val_miou=0.8662、私有 best_loss=0.3029，已经接近第一梯队。这说明模型结构差异确实会影响结果，但即便模型继续升级，问题仍不会自动转化为“语义类别自然分开”。本质瓶颈依然在结构表达和类别解释层，而不只是 backbone 或 decoder 的选择。

数据层面的结果同样非常关键。当前全量私有数据复杂度分层为 L1=48、L2=84、L3=65。这意味着样本本身就不是单一难度分布，而是天然存在“独立缺陷图”“低数量但高聚集图”“高复杂度密集图”三种显著不同的形态场景。再结合形态规则分类结果，197 张图中共得到 91235 个连通结构，其中被规则归为 uncertain 的仍有 16610 个。这一结果非常关键，因为它说明：即使在已有分割和规则体系下，大量结构仍然无法被稳定地解释成单一类别，说明“后分割结构解释”才是当前研究主问题。

此外，检测线实验也从侧面支持这一判断。B2_nwd_only_phase3e 相比历史 baseline，将 scratch AP50 从 0.4525 提升到 0.4671，mAP50 从 0.6765 提升到 0.6844。这说明检测模型更适合承担候选生成与粗召回角色，而不是成为最终结构解释的核心。也正因此，项目当前已经明确采用“分割为主干、检测为辅助”的协同原则。

四、当前任务与一般分割问题的根本差异

一般语义分割问题的标准表述是：给定图像，对每个像素赋予类别标签，并用 IoU、Dice 等指标评价预测与标注的一致性。这一表述默认了两个前提：第一，像素级类别本身就是最终问题；第二，标注对象的类别语义与空间结构是一一对应的。

而在当前暗场缺陷场景中，这两个前提都不完全成立。

首先，像素级前景并不是最终目标。即使所有缺陷区域都被完整切出来，研究与工程任务仍然没有真正完成，因为后续仍然必须回答：这些区域中哪些对应 spot，哪些对应 scratch，哪些只是由多条 scratch 聚合成的高风险区域，哪些已经不应再被看作“一个实例”，而应被解释为区域级 critical/crash 状态。

其次，空间连通性与物理语义并不是一一对应的。一个连通域可能包含多条交叉划痕，一个大片区域可能既有线状骨架，也有块状损伤；多条相邻划痕在阈值分割后很容易并成一个整体，但这并不意味着它们在物理意义上是“一个缺陷”。因此，“连通域 = 实例 = 类别”的朴素假设在这里会系统性失效。

第三，区域级类别和基础结构类别并不处于同一层级。spot / scratch / damage 更接近基础形态类别，而 critical/crash 更接近区域级复合状态。后者不应简单等价于某个单实例的 mask，而更像是多个基础结构在局部空间中形成的高密度、高交叉、高风险组合。也正因为如此，后续方法设计不能只追求单层语义分割，而必须考虑层级化标签和层级化推理。

五、问题的理论分解：从前景提取到结构解释

基于当前实验和数据现象，后续研究问题可以被系统地分解为五个连续层次。

第一层是缺陷区域提取。这一层的目标不是精确类别判断，而是以尽可能高的召回率稳定捕获所有可能的异常高灰度区域。从理论上看，这一层更接近灰度阈值化、局部对比增强、弱标签生成和缺陷前景召回问题。

第二层是结构基元提取。在已经得到的缺陷区域内部，需要进一步提取能够表征结构的中间表示，例如骨架、分叉点、交叉点、端点、局部平均宽度、细长比、局部密集度、最大连通区占比、区域位置等。换句话说，这一层关注的不是语义标签，而是结构描述符。

第三层是重叠与交叉结构拆解。对于多条划痕交叉、片状损伤与线状结构重叠、局部高密度聚集等情况，仅靠连通域并不能恢复真实缺陷数。此时需要思考的问题是：一个连通的亮区内部是否包含多个潜在结构单元；这些结构之间是接触、交叉、遮挡，还是已经形成新的区域级复合状态；在多大程度上需要做显式实例拆分，在多大程度上又应该保留为区域级整体解释。

第四层是类别和风险判定。这一层不是简单把每个像素再分类一次，而是把第二层和第三层提取出的结构信息映射到缺陷语义。这里尤其需要注意区分“基础形态类别”和“区域级风险类别”。前者更像 spot / scratch / damage，后者更像 critical/crash。

第五层是标签构建与迭代增强。由于当前私有数据集大部分仍是弱标签或无标签状态，前四层的输出最终都要服务于标签更新闭环。这意味着，方法设计不仅要考虑单次推理效果，还要考虑是否便于构造高质量伪标签、是否便于人工复核高分歧样本、是否便于反向提升下一轮模型。

六、为什么“重叠缺陷识别”是当前最核心的难点

从研究问题角度看，最值得单独抽出的核心难点是：对于分割后相互叠加、相互交叉、相互粘连的异形区域，如何恢复其中潜在的多个缺陷结构及其类别关系。

这一难点之所以成立，首先是因为阈值和一般分割网络都更容易输出“整体区域”，而不是“结构拆解后的多个物理缺陷”。只要多个缺陷在灰度空间上相互接近、在空间上相互接触，它们就很容易在 mask 中变成一个整体。

其次，镜片缺陷具有明显的异质性。有些缺陷是单点式的，有些是单条细线式的，有些则是由很多条短线、断裂线、交叉线、大片磨损块共同组成的复合区域。在这种情况下，强行把所有结构都映射为单层实例分割问题，往往会导致不稳定的标签定义和不稳定的评测口径。

再次，重叠缺陷本身可能并不总是应该完全拆开。有些交叉划痕从物理形成机制上确实可以被视为多条独立结构的相交；但有些高密度聚集区在工程上更关心的是其作为高风险复合区域的整体影响，而不是其中到底存在多少“理想化单条划痕”。因此，后续研究不仅要问“如何拆开”，还要问“哪些情形需要拆开，哪些情形应保留为复合区域”。

七、基于现有结果的工作假说

结合前期实验，当前可以提出一组对后续研究非常重要的工作假说。

第一个假说是：在暗场镜片场景中，缺陷前景提取的上限并不主要受限于更强的语义分割网络，而主要受限于后续结构解析和标签定义。换句话说，继续提高纯粹前景分割能力，收益会逐渐递减。

第二个假说是：当前最有效的分割模型应更多被视为结构信号提取器，而不是最终类别解释器。FPN 的优势在于几何稳定性，Unet++ 的优势在于细长结构敏感性，HRNet-OCR 的优势可能在于高分辨率保持，SegFormer-B2 的优势可能在于全局多尺度上下文；但这些优势最终都必须转译到结构解释层，才会变成真正可用的系统能力。

第三个假说是：对于复杂交叠缺陷，图结构、骨架网络和区域级复合判定，可能比单纯的像素分类更接近问题本质。也就是说，后续方法很可能需要从“像素分类模型”转向“像素 + 结构 + 关系”的混合表示。

第四个假说是：在标签稀缺条件下，最现实的路线不是直接做全自动实例级精确重建，而是采用“弱分割 -> 结构描述 -> 规则初判 -> 人工审核高分歧样本 -> 反哺训练”的逐层增强路线。当前复杂度分层和形态规则分类结果已经为这一假说提供了初步支持。

八、对后续文献和工程方案调研的建议问题框架

为了让后续 GPT 深度研究模式能够高效工作，建议把检索和比较问题明确组织成以下几组。

第一组问题是“哪些已有研究处理的其实不是普通语义分割，而是分割后的结构解析”。这类文献可能不一定来自镜片检测领域，还可能来自道路裂缝分析、纤维网络解析、血管分割后拓扑恢复、神经元分支解析、材料微裂纹识别、细胞团块实例拆解等邻近问题。后续调研应重点寻找那些“前景提取相对容易，但结构拆解和类别解释更难”的任务。

第二组问题是“哪些方法专门处理交叉线状结构、重叠细长目标或粘连异形区域的实例拆解”。这类工作可能会涉及骨架分解、图建模、端点匹配、交叉点归属、轮廓演化、拓扑保持分割、中心线追踪、嵌入学习、层级聚类、区域分裂与合并策略等。

第三组问题是“哪些方法把区域级复合类别与基础结构类别分开建模”。这与当前 critical/crash 的问题非常接近。后续需要重点寻找那些把基础实例和区域级风险状态分层表示的方法，而不是把所有类别都压在单一像素标签空间中的方法。

第四组问题是“在弱标签或无标签条件下，如何把简单阈值得到的前景区域进一步提升为高质量的结构标签”。这类工作可能与半监督分割、弱监督实例拆解、人机协同标注、图规则引导的伪标签提纯、多模型一致性筛选等方向相关。

第五组问题是“在灰度图、强背景对比但复杂结构重叠的场景中，传统方法与深度方法如何更合理地协同”。当前项目已经形成“分割为主干、检测为辅助”的原则，但后续还需要更系统地比较以下路线：传统阈值是否应作为第一层 mask 生成器，深度模型是否应更多服务于结构解释而非前景提取，形态规则是否应被纳入训练前的标签生成与训练后的结果解释两个阶段。

九、推荐的深度研究检索关键词与比较轴

为了提高后续文献与工程方案检索效率，建议优先围绕以下问题词展开，而不是只搜索“semantic segmentation for defects”。

优先检索词应覆盖以下概念簇：overlapping defect decomposition、crossing line structure segmentation、elongated instance separation、crack network parsing、skeleton graph decomposition、topology-preserving segmentation、weakly supervised defect instance separation、composite region classification、morphology-aware defect recognition、region-level risk classification、amodal instance reasoning、line network disentanglement、graph-based post-segmentation interpretation。

工程比较时，建议把候选方法统一放在以下比较轴上：第一，是否把问题当作前景提取，还是结构解析；第二，是否能显式处理交叉和重叠；第三，是否能同时支持基础结构类别和区域级复合类别；第四，是否适用于弱标签和人工审核闭环；第五，是否能输出可解释的物理量和结构属性；第六，是否能与当前项目的数据分层、形态规则和分割主线自然衔接。

十、当前研究结论的收束表达

基于当前实验，项目后续应当把研究目标从“继续提升像素级语义分割表现”重新收束为：在暗场镜片图像中，以缺陷区域稳定提取为起点，重点研究复杂异形区域的结构解析、重叠缺陷拆解、层级化类别判定与标签迭代增强。

这一定义意味着后续最值得做的工作，不是无限扩展新的分割 backbone，而是围绕以下路线展开：用传统方法和现有分割模型稳定得到缺陷区域，用结构描述符和图关系重建潜在缺陷单元，用层级化规则区分基础形态类别与区域级复合类别，用复杂度分层和高分歧样本审核控制标签质量，并最终把这些结果反哺到下一轮模型训练中。

如果这一问题定义成立，那么本项目下一阶段最重要的研究对象就不再是“语义分割模型本身”，而是“分割后结构理解”的方法体系。这也是后续深度研究、方法比较和实验设计应当围绕的真正主问题。
