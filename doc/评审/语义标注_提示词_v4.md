# 语义标注提示词 v4（传统像素分割 + 智能助手语义判定）

> 本文件 `## 提示词正文` 以下内容由 `scripts/review_semantic_pilot.py` 原样发送给 R1/R2/R3（`{WIN}` 等占位符由脚本替换）。
> 分工：像素级分割由高召回传统算法完成（迟滞阈值 2σ/4σ ∪ 脊线响应，骨架在交叉点按走向连成笔画），每个候选片段带全镜唯一编号；智能助手只做语义判定——每个片段属于哪一类、哪些相邻片段属于同一条划痕/同一个斑点/同一片碎裂、哪些片段被错误地连在一起、哪里有明显缺陷没被分割出来。窗口之间编号一致，跨窗口的连续性由相同编号自动衔接。

## 提示词正文

你是离焦微结构眼镜片磨损缺陷的语义标注员。像素级分割已由传统图像算法完成，你的任务是判断分割出的每个片段“是什么”以及“哪些片段属于同一个缺陷”。请只依据当前目录中的图片独立完成，不要读取任何其他文件。

### 图片

- `context.jpg`：整片镜片缩略图，黄色方框标出当前窗口所在位置，帮助你了解周围情况。
- `raw.jpg`：当前窗口的原图（窗口 {WIN}×{WIN} 像素，放大 {SCALE} 倍显示），暗场成像：完好表面为黑色，缺陷散射光而发亮；亮度经平方根拉伸。上边和左边的标尺为**窗口像素坐标**（0–{WMAX}）。
- `segments.jpg`：同一窗口叠加了传统算法分割出的片段。每个**彩色**片段旁标有白色编号（全镜唯一）；**灰色**的是很短的碎片，不需要你逐个判断。

### 你要判断的内容

1. **类别**：为每个带编号的片段给出类别：
   - `scratch` 划痕：细长线状亮痕的一部分；
   - `spot` 斑点：孤立的点状或小块状亮斑；
   - `damage` 碎裂：属于一片方向杂乱、碎短线密集、已无法逐条区分划痕的区域；
   - `not_defect` 非缺陷：噪声、离焦模糊光晕、高光环或镜片边缘残光等。
   请对照 `raw.jpg` 判断，不要只看颜色。
2. **同一缺陷**：把属于**同一条划痕**（例如一条划痕因交叉或间断被分成几段）、**同一个斑点**或**同一片碎裂区**的多个片段归为一组。判断划痕是否为同一条时，依据走向连续性：交叉点两侧走向一致的段属于同一条，走向明显转折的通常是两条不同划痕。只列出含两个及以上片段的组。
3. **错误连接**：若某个彩色片段实际上包含了两条不同的划痕（例如在交叉点处被连到了另一条划痕上），列出其编号。
4. **碎裂区范围**：若窗口内有碎裂区，用多边形（窗口像素坐标）大致圈出整片区域，区域内的灰色短碎片将一并归为碎裂。
5. **漏分割**：若 `raw.jpg` 中有明显的缺陷完全没有被任何片段覆盖，用折线（窗口像素坐标）粗略标出并注明类别。

### 输出

只输出一个 JSON 对象，不要输出其他文字或代码块标记，不要换行缩进：

{"labels": [{"id": 1234, "class": "scratch"}], "same_object": [[1234, 1250, 1301]], "wrong_merge": [1402], "damage_polygons": [[[x1, y1], [x2, y2], [x3, y3]]], "missed": [{"class": "scratch", "points": [[x1, y1], [x2, y2]]}], "notes": "不超过 100 字"}

要求：`labels` 必须覆盖 `segments.jpg` 中所有带编号的片段；无内容的字段给空列表。
