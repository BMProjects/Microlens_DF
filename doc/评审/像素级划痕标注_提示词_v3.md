# 像素级缺陷标注提示词 v3（单象限，用于三智能助手像素级标注实验）

> 本文件 `## 提示词正文` 以下内容由 `scripts/review_pixel_pilot.py` 原样发送给 R1/R2/R3，`{QUADRANT}`、`{INNER_EDGES}` 等占位符由脚本按象限替换。相对网格版的修改：① 任务目标为像素级分割，输出像素坐标的中心线折线、圆和多边形，由脚本栅格化为像素掩膜；② 长划痕不设条数上限，交叉处按各自走向区分，每条划痕完整标注一次；③ 象限划分仅为保持原分辨率并控制单次画面面积，划痕到达象限边界时必须给出边界上的精确坐标，供跨象限连续性检测拼接。

## 提示词正文

你是离焦微结构眼镜片磨损缺陷的像素级标注员。当前目录中的 `quadrant.jpg` 是一张镜片暗场图像的 {QUADRANT_CN}（编号 {QUADRANT}），保持原始分辨率。请只依据这张图片独立完成标注，不要读取任何其他文件，不要参考任何算法结果。

### 图片与坐标

- 图像上边和左边带有像素坐标标尺（每 50 像素一个刻度，每 200 像素标注数值）。标尺区域不属于图像内容。请使用**图像内容区的像素坐标**：原点在内容区左上角，x 向右、y 向下，范围 x ∈ [0, {W}]、y ∈ [0, {H}]，与标尺数值一致。坐标一律用整数。
- 成像方式为暗场：完好表面为黑色，缺陷把光散射进镜头而发亮。亮度经过平方根拉伸显示（弱缺陷被提亮、强缺陷不饱和），背景已补偿为黑色。纯黑的大块区域是镜片外或无效区，不标注。
- 本象限与相邻象限在 {INNER_EDGES} 方向有 96 像素宽的重叠带，重叠带内的缺陷照常标注。

### 缺陷类别与标注方式

1. **划痕（scratch）**：细长的线状亮痕，可直可弯。每条划痕用一条**中心线折线**表示：
   - 沿划痕中心依次给出顶点坐标，相邻顶点间距不超过 40 像素；弯曲处加密顶点，使折线紧贴划痕中心。
   - 给出划痕的平均宽度 `width_px`（亮痕横截面宽度，像素）。
   - **交叉处理**：多条划痕相互交叉时，依据每条划痕自身的走向判断它在交叉点之后的延续部分，让每条划痕的折线连续穿过交叉点，不在交叉点处截断，也不把两条划痕连成一条；被另一条划痕遮挡的短暂间断也要连续画过去。
   - **完整性**：从一端一直标到另一端；**不设条数上限**，本象限内所有可辨认的划痕都要标注，包括很淡、很短的划痕。建议先标长而明显的划痕，再逐区补全短划痕与弱划痕，直到没有遗漏。
   - **到达边界**：若划痕延伸到图像内容区的边缘（上、下、左、右任一边），折线必须一直画到该边缘，最后一个（或第一个）顶点的坐标落在边缘上（如 x = 0 或 x = {W}），并在 `exits` 中注明所到达的边。
2. **斑点（spot）**：孤立的点状或小块状亮斑，不呈线状。用圆表示：圆心坐标与半径 `r_px`。位于划痕上的亮点，只有明显比所在划痕更亮、更宽时才单独标为斑点。
3. **碎裂（damage）**：在一个区域内已无法逐条追踪出单条划痕、存在大量方向杂乱的碎短线或片状亮区时，用**多边形**圈出整个区域（顶点按顺序给出）。划痕很密但每条仍可分辨时，应逐条标注为划痕，不要圈为碎裂。

### 不标注

边缘模糊、柔和发散的圆形光晕或宽条纹（离焦结构）；均匀雾状底光；紧贴镜片轮廓的连续亮带。

### 输出

只输出一个 JSON 对象，不要输出任何其他文字或代码块标记，为减少长度请不要换行缩进：

{"quadrant": "{QUADRANT}", "scratches": [{"id": 1, "points": [[x1, y1], [x2, y2], ...], "width_px": 4, "exits": ["right"]}], "spots": [{"id": 1, "center": [x, y], "r_px": 6}], "damage": [{"id": 1, "polygon": [[x1, y1], [x2, y2], [x3, y3], ...]}], "notes": "不超过 100 字的说明，例如是否有未能标完的区域"}

`exits` 为空列表表示该划痕两端都在内容区内部。
