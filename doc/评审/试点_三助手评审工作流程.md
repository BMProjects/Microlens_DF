# 试点：三助手网格分割与分级评审工作流程

**目的：** 用 5 张不同磨损程度的镜片，检验三个智能助手（R1/R2/R3）独立完成“网格分割 + 分级”的一致性，并与传统图像算法对比，判断能否以智能助手替代人工标注审核的基础工作。

**原则（沿用计划 v2.0 第八章）：** 盲评、相互独立、不同模型、只读评审包；像素级与物理量由算法给出，助手只做网格级判断与分级；用户仲裁分歧。

## 一、评审包

`scripts/review_pilot.py build` 为每张镜片生成一个以随机编号命名的目录，内含：

| 文件 | 内容 |
|---|---|
| `overview.jpg` | 整镜概览（2000×1465，亮度 ×4），虚线圆标出 C/M/E 三个功能区 |
| `q1.jpg`–`q4.jpg` | 四个象限原分辨率图（2048×1500，亮度 ×4），叠加 16×12 网格，列 A–P、行 1–12，每格约 0.87 mm × 0.85 mm |

编号与镜片名的对照保存在 `output/review/pilot5/key.json`，不放进评审包。

## 二、提示词

统一使用 `doc/评审/试点_五图分割分级_提示词.md` 中“提示词正文”以下的内容，脚本运行时原样读取，三个助手完全相同。

## 三、运行方式

### 方式 1：脚本一次性运行（推荐，本次试点采用）

```
uv run python scripts/review_pilot.py build --lenses 108l 26l 90r 76r 72l
uv run python scripts/review_pilot.py traditional
uv run python scripts/review_pilot.py run --raters R1 R2 R3
uv run python scripts/review_pilot.py merge
```

`run` 会把评审包复制到项目目录之外的独立目录（每名评审员一份，样本顺序独立打乱），然后：

| 评审员 | 调用 | 隔离措施 |
|---|---|---|
| R1 | `claude -p <提示词> --model claude-opus-5-5 --effort high --allowedTools Read --output-format json --no-session-persistence` | 只允许读文件；工作目录只有评审包；不保存会话 |
| R2 | 同上，`--model claude-sonnet-5-5`（当前账号调用 `claude-fable-5-1` 提示需额外购买用量额度，改用同样可用、且与 R1 不同的 Sonnet 5.5） | 同上 |
| R3 | `codex exec -m gpt-6.1-sol -c model_reasoning_effort="high" -s read-only --skip-git-repo-check --ephemeral -i overview.jpg -i q1.jpg ...`，提示词经标准输入传入（`-i` 接受多个值，放在命令行末尾的提示词会被当作图片） | 只读沙箱；图片直接随提示词附上；不保存会话 |

结果写入 `output/review/pilot5/ratings/<评审员>_<编号>.json`。R1、R2 都在当前登录的 Claude 账号下运行；三人独立性来自“不同模型 + 独立会话 + 只读评审包”，与使用哪个账号无关。若需按账号分摊用量，可在第二个 Claude 账号登录后只运行 `run --raters R2`。

### 方式 2：手动切换账号运行

1. 进入某个评审包目录（如 `/tmp/microlens_review_pilot/R2/P41`）。
2. Claude 账号：`claude --model claude-sonnet-5-5 --effort high`，粘贴提示词正文；Codex：`codex -m gpt-6.1-sol -c model_reasoning_effort="high"`，粘贴提示词正文并附上 5 张图片。
3. 把助手输出的 JSON 保存为 `output/review/pilot5/ratings/R2_P41.json` 中的 `parsed` 字段（格式见脚本）。

## 四、汇总与判定

`merge` 计算：

- **分级一致性：** 三人等级完全一致的镜片数；多数等级。
- **网格分割一致性：** 每类缺陷的两两 Jaccard（交集/并集，按格子计）。
- **与传统算法对比：** 多数意见（≥ 2 人标出）与传统算法网格结果的 Jaccard。

## 五、三助手协作效率的优化要点

1. **无需人工切换账号：** 三名评审员由脚本并行调用，分批运行，结果自动落盘与汇总。
2. **统一 JSON 格式：** 输出可直接解析与比较，省去人工整理。
3. **分歧驱动：** 只把分歧格子（例如 1:2 或 1:1:1 的格子）裁成放大图进入第二轮评审或用户仲裁，一致格子不再重复审看。
4. **先校准再放量：** 试点与 T0 校准中暴露的系统性分歧（类别定义、离焦结构是否计入）先写入规程，再进入 T1 全量评审。
