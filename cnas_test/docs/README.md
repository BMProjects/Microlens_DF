# CNAS 测试文档源

本目录用于统一保存项目测试相关的结构化 Markdown 文档源和测试交付参考文件。这里的文档面向两类用途：

1. 当前中期测试与第三方评测准备；
2. 后续结题测试中对分割增强方案的扩展。

## 当前核心文档

- `CNAS测试大纲_当前版.md`
  统一版测试大纲，一份文件覆盖当前中期 `60%` 测试与后续结题 `90%` 测试。
- `CNAS测试报告_当前版.md`
  当前中期阶段的测试报告草稿，记录检测主线的正式预评测结果。
- `CNAS测试准备清单_20260321.md`
  测试准备、固定清单、命令、权重与执行前检查要点。

## 当前编制原则

- 当前中期测试以检测主线为正式被测对象；
- 测试口径必须兼容后续分割主线，不重复推翻重写；
- 一份测试大纲覆盖中期与结题两次测试；
- 项目和课题任务书中的指标要求优先于内部简化文档表述；
- `doc/` 中保留项目/课题任务书和总体研究文档；`cnas_test/docs/` 统一保留测试文档源与测试交付参考文件。
