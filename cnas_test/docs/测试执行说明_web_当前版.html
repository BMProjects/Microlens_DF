3. 方式一：单次测试

适用于已提供固定模型权重，仅执行第三方测试和报告生成。

cd /home/bm/Dev/Microlens_DF
OUT_DIR="cnas_test/outputs/$(date +%Y%m%d_%H%M%S)"
mkdir -p "$OUT_DIR"
uv run python -m cnas_test.runner.run_eval --save-dir "$OUT_DIR" 2>&1 | tee "$OUT_DIR/run_console.log"

如需指定被测权重，使用：

OUT_DIR="cnas_test/outputs/$(date +%Y%m%d_%H%M%S)"
mkdir -p "$OUT_DIR"
uv run python -m cnas_test.runner.run_eval \
  --weights /path/to/best.pt \
  --save-dir "$OUT_DIR" \
  2>&1 | tee "$OUT_DIR/run_console.log"

未指定 --save-dir 时，程序也会自动创建 cnas_test/outputs/YYYYMMDD_HHMMSS/ 时间命名目录。为同步保存终端日志，推荐显式设置 OUT_DIR。

4. 方式二：训练后测试

适用于需要先按当前数据集重新训练模型，再使用训练得到的 best.pt 执行测试。

cd /home/bm/Dev/Microlens_DF
mkdir -p output/experiments/cnas_full_retrain/logs
uv run --no-sync python scripts/train_phase2_sfe_nwd.py \
  --exp B2 \
  --device cuda \
  --epochs 60 \
  --batch 16 \
  --workers 8 \
  --lr0 0.001 \
  --project /home/bm/Dev/Microlens_DF/output/experiments/cnas_full_retrain/detection_training \
  --run-name LWIA-Det-v1.0.0-cnas-full-20260520 \
  --cache disk \
  --no-countdown \
  2>&1 | tee output/experiments/cnas_full_retrain/logs/train_full_20260520.log

训练完成后，使用训练输出目录中的 weights/best.pt 执行单次测试命令，并保存到新的时间命名目录。

5. 执行步骤

  1. 确认测试主机 GPU 可用，执行 nvidia-smi，记录截图。
  2. 确认项目根目录、测试集清单、模型权重或训练输出目录均存在。
  3. 选择“单次测试”或“训练后测试”路径执行命令。
  4. 测试程序自动生成启动截图、结果截图、指标图、溯源信息和报告。
  5. 打开 HTML/DOCX 报告，确认测试数据集、权重、指标、截图和日志完整。

9. 指标计算说明

对每个类别 c，预测框按置信度从高到低排序，并在 IoU = 0.5 条件下与同类别标注框进行一对一匹配。

Precisionc(k) = TPc(k) / [TPc(k) + FPc(k)]
Recallc(k) = TPc(k) / Ngt,c
AP50c = ∫01 Pc(R)dR，IoU = 0.5
mAP@0.5 = [AP50scratch + AP50spot + AP50critical] / 3
