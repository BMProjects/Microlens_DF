# 智能识别准确率测试大纲公式与符号汇总

以下内容为当前测试大纲中所有涉及公式和数学符号的 Markdown 规范稿，便于后续转换为 Word 并保持较稳定的渲染效果。

## 一、指标表述中使用的符号

本大纲保持“磨损识别准确率”作为统一的测试指标名称，以单张图像判定结果 \(\delta_i\) 为基础进行统计。

正式测试前，应登记测试图像集版本、基准结果版本、图像总数 \(N\) 和异常样本处理方式。

## 二、6.3.1 指标统计公式

设纳入本次统计的图像总数为 \(N\)。对第 \(i\) 张图像，记算法输出结果为 \(R_i\)，对应基准结果为 \(G_i\)，其单张图像判定结果为 \(\delta_i\)。

当第 \(i\) 张图像的识别结果满足本次测试确认的判定规则时：

\[
\delta_i = 1
\]

当第 \(i\) 张图像的识别结果不满足本次测试确认的判定规则时：

\[
\delta_i = 0
\]

则总体磨损识别准确率 \(A\) 按下式计算：

\[
A = \frac{1}{N}\sum_{i=1}^{N}\delta_i \times 100\%
\]

## 三、符号说明

- \(N\)：纳入统计的图像总数；
- \(i\)：图像序号；
- \(R_i\)：第 \(i\) 张图像的算法输出结果；
- \(G_i\)：第 \(i\) 张图像对应的基准结果；
- \(\delta_i\)：第 \(i\) 张图像的单张图像判定结果；
- \(A\)：总体磨损识别准确率。

## 四、判定规则相关表述

\(\delta_i\) 的具体定义应在正式测试前明确，并在同一次测试中保持一致。判定规则宜明确比较方式、对应阈值以及异常样本处理原则。

依据判定规则逐图像计算 \(\delta_i\)，并按公式计算总体磨损识别准确率 \(A\)。

是否通过测试，应以磨损识别准确率 \(A\) 与任务书、委托测试文件或测试实施细则中规定的阈值比较后确定。
