## 3. 方式一：单次测试

适用于已提供固定模型权重，仅执行第三方测试和报告生成。

```bash
cd /home/bm/Dev/Microlens_DF
OUT_DIR="cnas_test/outputs/$(date +%Y%m%d_%H%M%S)"
mkdir -p "$OUT_DIR"
uv run python -m cnas_test.runner.run_eval --save-dir "$OUT_DIR" 2>&1 | tee "$OUT_DIR/run_console.log"
```

如需指定被测权重：

```bash
OUT_DIR="cnas_test/outputs/$(date +%Y%m%d_%H%M%S)"
mkdir -p "$OUT_DIR"
uv run python -m cnas_test.runner.run_eval \
  --weights /path/to/best.pt \
  --save-dir "$OUT_DIR" \
  2>&1 | tee "$OUT_DIR/run_console.log"
```

说明：如不指定 `--save-dir`，程序也会自动生成 `cnas_test/outputs/YYYYMMDD_HHMMSS/` 形式的时间命名目录。为便于同步保存控制台日志，推荐按上述方式显式设置 `OUT_DIR`。

## 4. 方式二：训练后测试

适用于需要先按当前数据集重新训练模型，再使用训练得到的 `best.pt` 执行测试。

```bash
cd /home/bm/Dev/Microlens_DF
mkdir -p output/experiments/cnas_full_retrain/logs
uv run --no-sync python scripts/train_phase2_sfe_nwd.py \
  --exp B2 \
  --device cuda \
  --epochs 60 \
  --batch 16 \
  --workers 8 \
  --lr0 0.001 \
  --project /home/bm/Dev/Microlens_DF/output/experiments/cnas_full_retrain/detection_training \
  --run-name LWIA-Det-v1.0.0-cnas-full-20260520 \
  --cache disk \
  --no-countdown \
  2>&1 | tee output/experiments/cnas_full_retrain/logs/train_full_20260520.log
```

训练完成后，使用训练输出目录中的 `weights/best.pt` 执行第 3 节单次测试命令，并将测试结果保存到新的时间命名目录。

## 9. 指标计算说明

对每个类别 \(c\)，预测框按置信度从高到低排序，并在 \(IoU = 0.5\) 条件下与同类别标注框进行一对一匹配。第 \(k\) 个阈值位置的精确率和召回率为：

\[
Precision_c(k)=\frac{TP_c(k)}{TP_c(k)+FP_c(k)}
\]

\[
Recall_c(k)=\frac{TP_c(k)}{N_{gt,c}}
\]

类别平均精度 \(AP50_c\) 为精确率-召回率曲线下面积：

\[
AP50_c=\int_0^1 P_c(R)\,dR,\quad IoU=0.5
\]

主指标 \(mAP@0.5\) 为三类 \(AP50\) 的算术平均：

\[
mAP@0.5=\frac{1}{3}\left(AP50_{scratch}+AP50_{spot}+AP50_{critical}\right)
\]
